# খামারচক্র (KhamarChakra)

খামার ও কৃষির বর্জ্যের লাইভ বাজার: খামারি তালিকা দেয়, রিসাইকেলিং কোম্পানি দর দেয়,
সিস্টেম দূরত্ব ও পরিবহন খরচ বাদ দিয়ে "হাতে কত থাকবে" হিসাব করে দেখায়।

React 18 + Vite। কোনো ব্যাকএন্ড লাগে না — এখন সবকিছু ব্রাউজারে সিমুলেটেড (ডেমো)।

## চালানো
    npm install
    npm run dev       # লোকাল সার্ভার
    npm run build     # dist/ ফোল্ডার তৈরি

## Vercel-এ ডিপ্লয়
1. GitHub-এ নতুন রিপো বানিয়ে এই ফোল্ডারের ফাইল push করুন (node_modules ও dist বাদে — .gitignore আছে)।
2. vercel.com → Add New Project → রিপো বেছে নিন। Vite নিজে শনাক্ত হবে; Build: `npm run build`, Output: `dist`।
3. Deploy চাপুন।

## পাতা
- আজকের হাট: লাইভ দর-বোর্ড, খোলা তালিকা, মানচিত্র, সাম্প্রতিক কার্যক্রম
- বিক্রি করুন: ফর্ম + ক্রেতাদের মিল-হিসাব, দর গ্রহণ
- কিনুন: ক্রেতার ডেস্ক (ফিল্টার, পৌঁছানো খরচ, তালিকা নেওয়া)
- মূল্য-গাইড: একই বর্জ্য কাঁচা বনাম প্রক্রিয়াজাত করলে কত
- প্রভাব: মোট বর্জ্য, আয়, কার্বন সাশ্রয়, বাজার সূচক

## আসল ডেটা যুক্ত করতে
- `src/hooks/useMarket.js` — simulation (`init`, `tick`) বাদ দিয়ে Supabase/Firebase/API থেকে একই আকারের ডেটা দিন।
- `src/data/*.js` — বর্জ্যের ধরন, জেলা, ক্রেতা। সব দাম ও রূপান্তর হার আনুমানিক নমুনা; বাস্তব ডেটা দিয়ে বদলান।
- `src/lib/match.js` — পরিবহন খরচের হার (৳/কেজি/কিমি) ও স্কোরের সূত্র।
- `src/i18n.js` — বাংলা/ইংরেজি সব লেখা।
