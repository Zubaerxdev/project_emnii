## 💡 সমস্যাটা কী?

বাংলাদেশ কৃষিপ্রধান দেশ। প্রতিদিন খামার ও মাঠে প্রচুর বর্জ্য তৈরি হয়: গোবর, মুরগির লিটার, নারকেলের খোসা, ধানের তুষ, চিংড়ির খোসা। অথচ এগুলোর অনেকটাই বায়োগ্যাস, জৈব সার, ব্রিকেট, কয়ার ফাইবার বা পশুখাদ্যের কাঁচামাল হতে পারে।

সমস্যা হলো, **যার বর্জ্য আছে** আর **যার বর্জ্য দরকার**, তাদের মধ্যে কোনো সরাসরি যোগাযোগ নেই।

## ✨ খামারচক্র কী করে?

খামারচক্র সেই যোগাযোগটা তৈরি করে। খামারি তালিকা দেয়, কোম্পানি দর দেয়, আর সাইট দেখিয়ে দেয় **দূরত্ব ও পরিবহন খরচ বাদ দিয়ে খামারির হাতে আসলে কত থাকবে**।

| পাতা | কী পাবেন |
|---|---|
| 🏪 **আজকের হাট** | ১৩ ধরনের বর্জ্যের লাইভ দর-বোর্ড, খোলা তালিকা, বাংলাদেশের মানচিত্র, সাম্প্রতিক কার্যক্রম |
| 💰 **বিক্রি করুন** | তালিকা দেওয়ার আগেই সেরা ক্রেতা, দূরত্ব, পরিবহন ও নিট আয়ের হিসাব; দর এলে গ্রহণ |
| 🏭 **কিনুন** | ক্রেতার ডেস্ক: ফিল্টার করে পৌঁছানো খরচসহ তালিকা দেখা ও নেওয়া |
| 📊 **মূল্য-গাইড** | একই বর্জ্য কাঁচা বিক্রি বনাম প্রক্রিয়াজাত করলে কত লাভ |
| 🌍 **প্রভাব** | মোট বর্জ্য, খামারিদের আয়, কার্বন সাশ্রয়, বাজার সূচক |

## 🧮 হিসাব কীভাবে হয়?

```text
ক্রেতার দর  = আজকের বাজারদর × ক্রেতার গুণক
হাতে পাওয়া = ক্রেতার দর − পরিবহন খরচ   (ক্রেতা নিজে নিলে পরিবহন ০)
মিল স্কোর   = হাতে পাওয়া দাম (৫৫) + ক্রেতার সক্ষমতা (২৫) + কাছে থাকা (২০)
```

পরিবহন ধরা হয়েছে প্রায় ৳৯ প্রতি টন-কিমি, আর সড়কপথ সরলরেখার ১.৩ গুণ।

## 🚀 লোকালে চালানো

```bash
git clone https://github.com/তোমার-ইউজারনেম/khamar-chakra.git
cd khamar-chakra
npm install
npm run dev
```

তারপর ব্রাউজারে `http://localhost:5173` খুলুন। প্রোডাকশন বিল্ডের জন্য `npm run build` চালান, ফল পাবেন `dist/` ফোল্ডারে।

## ☁️ Vercel-এ ডিপ্লয়

1. এই রিপো GitHub-এ push করুন।
2. [vercel.com](https://vercel.com) → **Add New Project** → রিপো বেছে নিন।
3. Framework: **Vite**, Build: `npm run build`, Output: `dist`।
4. **Deploy** চাপুন।

## ⚠️ ডেমো সংস্করণ সম্পর্কে

এটি একটি **ডেমো**। এখানে খামারি, ক্রেতা, দর ও তালিকা সব **কাল্পনিক ও সিমুলেটেড**। দাম, রূপান্তর হার ও কার্বন হিসাব আনুমানিক নমুনা, যাচাই করা বাস্তব ডেটা নয়। আসল ব্যবহারের আগে ডেটাবেস, ক্রেতা-যাচাই ও স্থানীয় বাজারদরের সঙ্গে মিলিয়ে নেওয়া দরকার।
